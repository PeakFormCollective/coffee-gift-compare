Example answers you can adapt

Replace the bracketed parts with what's actually true for you. Only claim what you can show.

MFA: "Multi-factor authentication is enforced for [email/workspace, cloud console, code repository]. [Any system without MFA] is scheduled to have MFA enabled by [date]."
Encryption: "Data is encrypted in transit using TLS. Customer data at rest is encrypted using [provider]-managed encryption for [database/storage]."
SOC 2 (if you don't have a report): "We do not currently have a SOC 2 report. Our controls include [MFA, encryption, access reviews, backups], and we can provide further detail on request."
Incident response: "We follow documented incident response steps: detection and triage by [role], containment, customer notification without undue delay, and a post-incident review."
Access reviews: "Access rights to production and admin tools are reviewed [quarterly] by [role], and access is removed [same day] when someone leaves."
Backups: "Customer data is backed up [daily] and retained for [30] days. A restore was last tested on [date]."
